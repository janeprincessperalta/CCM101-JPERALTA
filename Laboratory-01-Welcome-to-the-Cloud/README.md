# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the fundamentals of working in a cloud-based Linux environment. The activity was completed using the KillerCoda Playground and GitHub.

The mission focuses on accessing a Linux environment, creating a user account, exploring the Linux system, gathering system information, organizing files and directories, and documenting the completed activities in a GitHub repository.

## Objectives

The objectives of this laboratory activity are to:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Create and use a Linux user account.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical activities using Markdown.
- Practice proper documentation and version control.

## Activities Performed

The following activities were completed:

1. Accessed the Ubuntu 24.04 Linux Playground using KillerCoda.
2. Verified that the terminal was functioning correctly.
3. Created a new Linux user with a home directory and sudo privileges.
4. Logged in to the newly created user account.
5. Recorded the current username, working directory, and hostname.
6. Investigated the Linux distribution and system information.
7. Created the required directory structure.
8. Created and viewed Markdown documentation files.
9. Created a public GitHub repository for the Cloud Computing Portfolio.
10. Uploaded screenshots and laboratory documentation to GitHub.
