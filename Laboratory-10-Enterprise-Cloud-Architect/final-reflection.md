
# Final Reflection: Enterprise Cloud Architect

To conclude, Through this project, we learned how to install and use Ubuntu Server in VirtualBox, configure Docker Compose, and run WordPress and MariaDB containers. We also learned how to connect WordPress to MariaDB and check if both containers are running properly.
We gained hands-on experience using Docker volumes to store website and database data, checking network and firewall settings, and creating database backups using a Bash script. We also learned how to schedule automatic backups using Cron.
Overall, this project helped us understand how to deploy, test, and maintain a WordPress website using Docker Compose. It also improved our practical skills and knowledge in Cloud Computing.
