## **Questions and Answers**

### **1. Which cloud provider offers the broadest range of services?**

AWS provides the widest selection of cloud services among the three major platforms. It offers solutions for computing, storage, databases, networking, security, analytics, and many other cloud requirements. This makes AWS suitable for organizations with different types of projects and workloads.

### **2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure has the strongest connection with Microsoft technologies. It works well with products such as Windows Server, SQL Server, Microsoft 365, and other Microsoft services. Because of this, Azure is a convenient choice for organizations that already use a Microsoft-based environment.

### **3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

Google Cloud Platform (GCP) is particularly strong in Artificial Intelligence and Kubernetes. It provides tools for AI development, data analysis, and machine learning. It also offers Google Kubernetes Engine (GKE), which helps organizations run and manage containerized applications.

### **4. Which cloud platform would you personally choose and why?**

I would personally choose AWS because it offers a wide variety of services that can be used for different types of projects. As an IT student, learning AWS would allow me to gain practical knowledge in areas such as computing, storage, databases, networking, and security. These skills can also be useful for future cloud-related projects and work.
