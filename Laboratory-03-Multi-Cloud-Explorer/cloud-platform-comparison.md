## **Questions and Answers**

### **1. Which cloud provider offers the broadest range of services?**

AWS has the largest variety of cloud services among the three platforms. It provides solutions for areas such as computing, data storage, databases, networking, security, and analytics. Because of this, organizations can use AWS for many different types of projects without depending on several separate platforms.

### **2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure is the best option for organizations that use Microsoft technologies. Its services are closely connected with products such as Windows Server, SQL Server, and Microsoft 365. This makes Azure convenient for businesses that already have a Microsoft-based IT environment.

### **3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

GCP stands out in Artificial Intelligence and Kubernetes. Google provides several technologies for AI and data analysis, while Google Kubernetes Engine (GKE) gives organizations a managed platform for running containerized applications.

### **4. Which cloud platform would you personally choose and why?**

Personally, I would select AWS because of its flexibility and wide selection of services. It can be used for different projects, from simple applications to larger cloud systems. For me as an IT student, exploring AWS would also provide useful experience with important cloud concepts such as virtual machines, storage, databases, networking, and security.
