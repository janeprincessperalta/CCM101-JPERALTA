# **Cloud Platform Recommendation Challenge**

## **Client A – Startup Company**

### **Recommended Cloud Platform: Amazon Web Services (AWS)**

I would choose AWS for the startup because it provides a practical way to build an application without requiring the company to purchase and maintain its own servers. The startup can begin with a basic cloud environment and expand its resources as the number of users and business activities increase. This makes AWS a suitable platform for a company that wants to keep its initial expenses manageable while having room for future expansion.

AWS services can support the main parts of the mobile application. EC2 can provide the computing environment, S3 can be used for storing application-related files, and RDS can handle the database where important application information is kept.

**Recommended Services:**

* Amazon EC2 – for providing the computing environment needed by the application
* Amazon S3 – for storing images, documents, files, and other application content
* Amazon RDS – for handling and maintaining the application's relational database

## **Client B – University**

### **Recommended Cloud Platform: Microsoft Azure**

Microsoft Azure is a strong choice for the university because its current systems already use Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory. Azure can work together with these existing technologies, which can make the move toward cloud services more manageable. Its hybrid cloud capabilities also allow the university to connect its current infrastructure with cloud-based resources.

**Recommended Services:**

* Azure Virtual Machines – for running Windows-based applications and server workloads
* Microsoft Entra ID – for managing user accounts, authentication, and access permissions
* Azure Blob Storage – for storing academic documents, files, and other digital resources

## **Client C – AI Research Company**

### **Recommended Cloud Platform: Google Cloud Platform (GCP)**

Google Cloud Platform (GCP) is a suitable choice for the research company because its main focus is artificial intelligence and machine learning. GCP provides tools for AI development, data processing, and demanding computing tasks. These capabilities can help the company perform research, develop models, and bring AI solutions into actual use.

**Recommended Services:**

* Google Compute Engine – for providing computing resources for AI and research workloads
* Google Kubernetes Engine (GKE) – for running and managing container-based applications
* Vertex AI – for developing, training, and deploying artificial intelligence and machine learning models

## **Client D – Global E-Commerce Company**

### **Recommended Cloud Platform: Amazon Web Services (AWS)**

AWS is a good choice for the global e-commerce company because its online platform needs to remain accessible to customers from different locations. The company also needs infrastructure that can handle changes in website traffic, especially during busy shopping periods. AWS provides global infrastructure and scalable services that can help the e-commerce platform maintain reliable performance as demand changes.

**Recommended Services:**

* Amazon EC2 – for running the e-commerce website and application
* Amazon S3 – for storing product images, files, and other website content
* Elastic Load Balancing – for distributing customer traffic across multiple application servers
